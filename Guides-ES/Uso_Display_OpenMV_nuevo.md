### NOTA: esta guia esta hecha para el firmware 4.8.1 o posterior, para la version 4.4.1 o anterior, puedes usar esta [Guia](pantalla_legacy/Uso_Display_OpenMV.md)
### 1. Requisitos previos
Primero necesitas que tu placa esté flasheada con el firmware de **OpenMV**  
(la información se encuentra en el siguiente documento:  
[Flasheo para OpenMV (Windows)](Windows/Flasheo_Firmware_OpenMV.md) | [Flasheo para OpenMV (Linux)](Linux/Flasheo_Firmware_OpenMV.md))

---


### 2. Archivos del ejemplo en el repositorio

En la carpeta del repositorio **Display/4.8.1** encontrarás un archivo.  
El archivo **main.py** es donde puedes usar las funciones del display.

Actualmente `main.py` incluye un ejemplo que muestra el feed de la camara.
